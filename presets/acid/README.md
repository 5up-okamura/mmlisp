# 303風の通常FMベース

[音色ライブラリ](tb303.mmlisp) /
[フレーズを含む鋸歯状波デモ](../../examples/source/acid-saw.mmlisp)

YM2612の通常FMを1チャンネル使用します。CSM・PCM・外部エフェクトは使用しません。

| 定義 | 内容 |
| --- | --- |
| `acid-saw` | 鋸歯状波風ベース。倍音の多いアタックから減衰 |
| `acid-square` | 矩形波風ベース。奇数倍音中心の中空な音 |
| `acid-normal` | 通常音: velocity 12、控えめな変調量 |
| `acid-accent` | アクセント: velocity 15、強い変調量、速い変調器の減衰 |
| `acid-pattern-16` | Eを中心にした16ステップのフレーズ |

`acid-saw`と`acid-square`だけを音色ライブラリで定義しています。
`acid-normal`、`acid-accent`、`acid-pattern-16`は各デモスコア内に直接定義しています。

## 使い方

`examples/source/`にスコアを置く場合:

```lisp
(import "../../presets/acid/tb303.mmlisp")

(fm1 :tempo 130 :oct 2 :len 16 :vol 31
  acid-saw
  e e _
  e ~ (glide 32) g
  (glide none) b _ d)
```

`acid-square`に置き換えると同じ演奏で矩形波版になります。
[鋸歯状波デモ](../../examples/source/acid-saw.mmlisp)と
[矩形波デモ](../../examples/source/acid-square.mmlisp)は同じ16ステップを4回演奏します。

フレーズは`:len 16`を前提にし、ゲート操作なしで音長を指定しています。
通常の音は音長いっぱい鳴らしても次の音で再アタックします。
例えば`:len 16 e32 e32 e e`で32分音符2つと16分音符2つを演奏できます。
グライド時間は32分音符です。
130 BPMではステップ約115 ms、スライド約58 msになります。
テンポを変えるとスライド時間も変わるため、実機303の時間特性と完全には一致しません。

| ステップ | 音（開始オクターブ2） | 演奏 |
| --- | --- | --- |
| 1–3 | E2 E2 休符 | 通常音 |
| 4–5 | E2 → G2 | アクセントからスライド |
| 6–8 | B2 休符 D2 | 通常音 |
| 9–10 | E3 → D3 | アクセントからスライド |
| 11–13 | B2 休符 G2 | 通常音 |
| 14–15 | E2 → B2 | 通常音からスライド |
| 16 | E2 | 通常音 |

## スライドとアクセント

スライドは`~`によるレガートと`(glide 32)`の組み合わせです。
左の音から右の音へはキーオフせず、音程だけを移動します。
スライド先の音が終わるとキーオフし、次の通常音で再アタックします。
スライド先でFMエンベロープは再トリガーしません。

```lisp
; :len 16 のトラック内
acid-accent e ~ (glide 32) g
(glide none) acid-normal b _
```

`acid-normal`と`acid-accent`は、音量に加えて変調器のTL・DRを同時に変更します。
SL/DRによる変調量の減衰がフィルターを閉じるような音色変化を作ります。
スライド区間にはこれらの切替を挟まず、開始音のエンベロープを継続します。

## 1つのスライダーで複数の値を動かす

両デモには`color`スライダーがあります。LiveのDynamic Parametersで操作できます。
右へ動かすほど3つの変調器の変調量が増え、明るさの減衰も緩やかになります。

```lisp
(def-val color 8 16..0 :step 1)
(def acid-normal :vel 12
  :tl1 (+ 22 $color)
  :tl2 (+ 26 $color)
  :tl3 (+ 24 (* $color 2))
  :dr3 (+ 6 $color)
  :sl3 5)
```

`$color`を複数の式から参照して連動させます。足す値で基準を、掛ける値で変化幅を決めます。
TLは小さいほど変調が強くなるため、範囲を`16..0`に反転しています。
初期値8は従来の設定と同じです。アクセントにも同じスライダーを使い、基準値だけ変えています。

値は`acid-normal`／`acid-accent`を実行した時に読み取ります。
フレーズでは各アタックの直前に置いてあるため、操作は次のアタックから反映されます。
スライド先では読み直さず、つながった音のエンベロープを維持します。
保持中の音へ連続的に追従する仕組みではありません。

## 調整

- 明るさの範囲: `acid-normal` / `acid-accent`内の`:tl1`–`:tl3`の式。小さくすると倍音が強くなります。
- 明るい部分の長さ: 同じ定義の`:dr3`の式。大きくすると速く暗くなります。
- 減衰後の明るさ: `:sl3`。大きくすると変調量がより深く減衰します。
- アクセント差: `:vel`と`:tl1`–`:tl3`を調整。
- スライド速度: フレーズ内の`(glide 32)`を変更。

音色は`acid-saw`／`acid-square`で直接定義し、音高・共有LFOレートは変更しません。
AMS/FMSは音色の値（0）を設定します。デモのフレーズ終了時は通常音・glide無効に戻ります。

## 検証と限界

両スコアをIRとMMBにコンパイルし、4小節で52ノート、12スライド、40回のキーオンを検証。
IRとドライバのキーオン回数が一致し、IRレジスタログでは各スライドの接続前後に
キーオン／キーオフが入らないことも確認しています。
IRとMMBドライバの両方で、次のアタックの前にキーオフが発行されることも検証しています。
スコアに1フレームの空きを設ける必要はありません。

スライダーの0・8・16で、通常音／アクセントの4パラメータが期待どおりのレジスタ値になることを確認しています。

試聴WAVは`color = 8`固定です。実際のスコアをIRPlayerで再生したレジスタログからNuked-OPN2で生成しました。
16-bit mono、コアのネイティブレートを丸めた53,267 Hzです。
試聴WAVのみ全体のDC除去と一定ゲインを適用しています。
ノートごとの音量合わせ、歪み、フィルター、リバーブはかけていません。

これは303の回路再現ではありません。変調量の変化は本物のカットオフ／レゾナンスとは異なり、
303特有のアクセント回路の蓄積・非線形応答も再現していません。
聴感による最終評価は未実施です。

```sh
node tools/scripts/render-acid-fm.mjs
```
